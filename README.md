# Elad Asis

A one-page site for hiring teams. It presents Elad’s career, full-stack and AI skills, education, and contact details. Built with Next.js, React, and TypeScript.

For a walkthrough of the code, see [tutorial.md](tutorial.md).

## Run it locally

You need [Node.js](https://nodejs.org/) installed (this project was built with Node 22).

1. Open a terminal in this folder.
2. Install the dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000).

The page reloads when you save a file. Stop the server with `Ctrl+C`.

## Production build

```bash
npm run build
npm start
```

`npm start` also serves the site at [http://localhost:3000](http://localhost:3000). Run it only after `npm run build`, and not while `npm run dev` is already using that port.
